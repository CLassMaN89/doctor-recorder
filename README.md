# Doktor Kayıt v7.0
- Kayıt state machine düzeltildi: Başlat -> Durdur -> Devam Et / Kaydı Bitir.
- Kaydı Bitir sonrası süre kesin olarak 00:00 ve idle; otomatik yeniden kayıt yok.
- Gerçek mikrofona bağlı çok katmanlı Siri-benzeri canlı dalga.
- Telefonda Kayıtlarım listesi ve oynatma.
- Dar masaüstü pencerelerinde compact responsive tasarım; ham/native buton görünümü engellendi.
- Backend device-recordings endpoint'i eklendi; telefon sadece kendi device_connection kayıtlarını alır.

GitHub kökünde index.html, style.css, app.js dosyalarını değiştirin.
